My endpoints are used for uploading the dataset, retrieving the dataset, and retrieving and validating the dataset. The src folder has models.py which handles initiation and validation using declared fields, storage.py which can store data after an upload so a later request can retrieve it, and middleware.py which share tasks across multiple endpoints. We use the data_pipeline folder to validate, process, and update the data. Main.py uses all of these files to run an application that receives requests, run the code, and returns a response. The tests folder uses conftest.py and test_api.py to test if the application is working correctly.
